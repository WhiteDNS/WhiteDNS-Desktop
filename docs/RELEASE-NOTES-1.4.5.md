# WhiteDNS Desktop 1.4.5

Fix CottenMax connection and scan startup with long account domains generated by WhiteDNS Server Management. Runtime configurations automatically reserve enough initial DNS query-name space for the handshake, including standby domains, payload-label shaping and optional label-count jitter.

Stored settings and sparse settings exports are preserved. Higher custom budgets remain in effect; Normal mode retains its existing behavior. The embedded Cotton core remains pinned to `7db7b73658c791cce62300d29647e4d369d6e1e4`.

Update panel-managed servers to WhiteDNS Server Management 0.10.0. Existing account domains, shared keys and subscription URLs remain valid. Existing Max-capable standalone servers need no configuration change for this fix.

Rendering regression tests and the Desktop suite cover this adapter change. Release CI builds Windows x64/ARM64, macOS Intel/Apple Silicon and Linux x64/ARM64 packages. Physical-device and restricted-network acceptance are not implied by build success.
